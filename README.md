# telemost-mini-app

Telegram Mini App — форма анкеты смены (БКСМН, кулинарное производство).

Открывается кнопкой `web_app` в клавиатуре Telegram-бота, позволяет мастеру
заполнить отчёт смены через форму (без ручного форматирования), нажимает
**Отправить** → `Telegram.WebApp.sendData(анкета)` шлёт боту сервисное
сообщение `web_app_data`. Бот (см. `telemost-bot` в agent-kit-pilot, issue #9)
принимает текст и прогоняет через генератор `бксмн.py` (два формата ФОТ+БКСМН,
валидация 9.6).

## Формат анкеты

Приложение собирает **тот же ключ-строчный текст**, который парсит
`telemost-bot/smeta.py` (полная схема — в модуле). Это гарантирует, что
рукописные ошибки формата (те самые, что ловил парсер) не возникают:
мастер заполняет поля, скрипт сам расставляет `участок:`, `позиция: ... | план | факт`,
`сотрудник:`, простои, ПК-блок, `состав:`.

## Как подключить к боту

1. Задеплой статику на GitHub Pages (корень = `index.html`).
2. У бота (через `setChatMenuButton` или клавиатурную кнопку `web_app`)
   указать URL Pages.
3. Кнопка `web_app` (Keyboard Button): `{ text: "📋 Заполнить отчёт", web_app: { url: "https://warnetbes.github.io/telemost-mini-app/" } }`
4. Сервисное сообщение `web_app_data.data` = текст анкеты → подать в `bot.py once`.

## Файлы

- `index.html` — форма для открытия в Telegram (подключает `telegram-web-app.js`).
- `preview.html` — тот же интерфейс для теста вне Telegram (без WebApp SDK).
- `app.js` — логика: сборка анкеты, валидация (зеркалит smeta.py), `sendData`.
- `style.css` — темы Telegram WebApp (свет/тёмная), мобильная вёрстка.

## Безопасность

- `initData` на фронте не доверяем — подпись валидирует бот на сервере
  (HMAC-SHA256 от `initData`, секрет = `bot_token`).
- `sendData` — строгий формат, анкета под 4096 байт (лимит `sendData`).
- Секреты/токен бота нигде в статике не хранятся.
